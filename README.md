# Dhruthi Wellness — Official Website & CEO's CRM

A modern, production-ready **CEO's CRM and Executive Client Management System** for Dr. Akhila Konakalla and team, seamlessly integrated with the official Dhruthi Wellness website, database, files, and communication platforms.

---

## 🌟 Key Features

- **CEO Command Center**: Executive dashboard featuring VIP Watchlist, Revenue Intelligence, real-time "Today's Priorities", and the "What Should I Do Now?" smart action panel.
- **Executive Login Gateway**: Secure PIN/passcode login for executive privacy and session security.
- **Keyboard Ergonomics**: Instant keyboard shortcuts (`?`, `g d`, `g l`, `g c`, `g b`, `c l`, `⌘K`) for high-velocity operation.
- **CEO 360° Medical History Snapshot**: Instant clinical history recall card summarizing conditions, allergies, lab markers, and progress trends.
- **Executive Diet Prep Studio & Calculators**: Mifflin-St Jeor metabolic BMR/TDEE calculator, macronutrient split, and 1-click WhatsApp/Print exporter.
- **Lead Pipeline & Scoring**: Kanban & Table views, 0–100 automatic lead scoring, lead temperature badges (HOT/WARM/NURTURE/COLD), and source attribution.
- **Website & Form Sync**: Real-time synchronization of website bookings (`/api/book`), contact inquiries (`/api/contact`), and payment proofs (`/api/payment-receipt`) with phone/email normalization and duplicate detection.
- **Spreadsheet Import Engine**: Interactive Excel (.xlsx, .xls, .csv) & Google Sheets wizard with auto column mapping, validation, duplicate strategies (`Skip`, `Update`, `Create`), and error downloads.
- **Communication Center**: Built-in adapters for WhatsApp Business API message history & templates, and telephony/calling log abstraction.
- **CEO Scratchpad**: Floating quick note panel for jottings thoughts on the fly.

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm start
```

Access:
- **Official Website**: http://localhost:3000
- **CEO's CRM**: http://localhost:3000/crm
- **Database Status**: http://localhost:3000/api/db-status
